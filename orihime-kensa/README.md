# OriHime 検査・修理管理（Google スプレッドシート + GAS）

OriHime の検査をチェック方式で行い、その結果から修理シートと履歴ガントを自動で作るための
Google Apps Script（GAS）です。

- スプレッドシート：マイドライブの「OriHime 検査・修理管理」
  https://docs.google.com/spreadsheets/d/1NT3B4WjAqmD2PlF7WVishUKVsDcYuA70rQVrTtL3gPA/edit
- コード：`Code.gs`（このファイル1つだけ）

## シート構成

| シート | 役割 | 誰が触るか |
|---|---|---|
| 使い方 | 手順書（OJT用） | 全員 |
| 検査シート | OK / △ / NG に☑ → 「保存して判定する」に☑ | 検査担当 |
| 修理シート | 要修理の機体が自動で並ぶ。ステータス・担当者・引き継ぎメモを更新 | 修理担当 |
| 履歴ガント | 行＝機体番号、列＝日付。検査・修理待ち・修理中・完了を表示 | 見るだけ |
| 部品在庫 | 在庫数を入れると、未完了の修理に必要な数と不足数を自動計算 | 管理者 |
| 検査記録 / 検査明細 / 修理部品明細 | GAS が自動で書く記録 | 触らない |
| 検査項目マスタ / NG詳細マスタ / 設定 | 検査項目・修理内容・部品・プルダウンの中身 | 管理者 |

## 初回セットアップ（1回だけ）

1. スプレッドシートを開き、メニュー「拡張機能 → Apps Script」を開く
2. 最初からある `コード.gs` の中身を全部消し、このフォルダの `Code.gs` の中身を貼り付けて保存
3. スプレッドシートを再読み込み → メニューに「OriHime管理」が出る
4. 「OriHime管理 → 履歴ガントを更新する」を一度実行し、権限の確認画面で「許可」する

以降は、シート上の☑だけで動きます（スマホ・iPad の Sheets アプリでも動作）。

## しくみ（コードの読み方）

- `onEdit(e)`：セルを編集するたびに自動で呼ばれる。☑のセルをボタン代わりにしている
- `saveInspection()`：入力チェック → 判定 → 修理シート登録 → 記録保存 → ガント更新
- `buildRepairPlan()`：NG 項目から「修理内容」と「必要部品」を組み立てる
  （NG詳細マスタ → 検査項目マスタの既定値 の順に探す）
- `rebuildGantt()`：検査記録と修理シートから、ガントを毎回作り直す
- 行・列の位置は先頭の `LAYOUT` にまとめてある。シートの配置を変えたらここを合わせる

## 判定ルール

- NG が1つでもある → 「要修理」（修理シートに登録）
- NG がなく △ がある → 「合格（△あり）」
- すべて OK → 「合格」
- 修理完了（再検査待ち）の機体を再検査して合格 → 修理を「クローズ」
- 再検査で NG → 同じ修理の行に追記して「未着手」に戻す
